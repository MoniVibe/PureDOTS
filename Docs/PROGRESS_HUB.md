# Progress Hub

This is the canonical progress entrypoint for agents.

## Canonical Direction Set
- `Docs/NORTH_STAR.md`
- `Docs/DEMO_SLICE.md`
- `Docs/ARCHITECTURE.md`
- `Docs/PERF_GATES.md`
- `Docs/NETPLAY_NOT_NOW.md`

## Current Tracking Rule
- Track execution status against scenarios, gates, and artifact proof.
- Prefer concise run-linked updates over narrative status dumps.

## Where To Record Work
- Run-level evidence: buildbox/anviloop artifacts and triage outputs.
- Planning/status notes: roadmap files under `Docs/Roadmaps/` when still active.
- Historical material: `Docs/Archive/` with tombstone links from any replaced entrypoint.

## Definition Of Up-To-Date
- Last update names scenario ids or workstreams, not just themes.
- Claims include proof pointers (meta/run_summary/watchdog/invariants).
- Any budget or rule change references the canonical docs above.
